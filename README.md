## Hey, I'm Mauricio 👋

DevOps Engineer based in Barranquilla, Colombia. I spend my days wiring up AWS infrastructure, shipping containers (the Docker kind), and building CI/CD pipelines that actually work. Currently at **ADO-TECH**, where I manage multi-account AWS environments, Fargate clusters, and client-facing deployments.

I hold the **AWS Solutions Architect – Associate (SAA-C03)** and **AWS Cloud Practitioner (CLF-C02)** certifications.

When I'm not deploying, I'm probably tinkering with CLI tools, writing Go, or playing Zenless Zone Zero.
